## Update to the Latest LYRX for Mac Users: Enhanced Karaoke Software with Catalina Support | Get Your Free PCDJ v1.n

[![Download LYRX update 1.6](https://i1.wp.com/pcdj.com/wp-content/uploads/2020/04/lyrx-16-cover-2.jpg?resize=845%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2020/04/lyrx-16-cover-2.jpg?fit=1030%2C757&ssl=1 "Download LYRX update 1.6")

**LYRX 1.6 (for Windows & Mac) is ready for download!**

We’re happy to announce LYRX is ready for macOS Catalina. The new 1.6 version of our newest and most popular karaoke software includes many under-the-hood updates and improvements — most notably the change over from the prior OpenGL API to Metal (macOS). As we wrote in a prior post, Catalina brought major changes to the macOS graphics API, moving from the OpenGL to Metal. This required our development team to refactor our graphics engine entirely. There will be notable benefits, especially as LYRX continues to grow.

![LYRX version 1.5 with LEARN feature](https://i1.wp.com/pcdj.com/wp-content/uploads/2019/07/lyrx-v15-learn.jpg?fit=300%2C169&ssl=1 "LYRX version 1.5 with LEARN feature")

Since our “code” is cross-platform the Windows version received the same graphics engine updates.

Development had to dig deep to make significant changes. As a byproduct, they were able to streamline some of the code for better overall performance. This benefits both the Windows & Mac versions, and will allow us to ‘build on’ to the existing LYRX platform with ease.

One other notable change is where LYRX stores your data. In prior versions we used “Documents” as the storage location for the LYRX data folder. This presented some problems with saving at times (largely due to permissions related issues, corrupt user profiles on Windows, Microsoft One Drive, and other security measures brought on by Catalina). When you install the new LYRX update it will migrate your existing user data to the new location so you will not need to start over. A new button has been added in LYRX’s options to access the new location of the LYRX data folder making for easy access.

Support for the new Music app (formally known as iTunes) is also included.

Now that this major maintenance release of LYRX is ready for live performance we can get back to the fun stuff! Quite a few features where shelved during the Catalina-specific re-write that we can get back to. Expect to see new features and other improvements soon!

As always, version 1.6 is a FREE upgrade for existing LYRX customers. Simply download and install the update with your existing version closed to update now!
