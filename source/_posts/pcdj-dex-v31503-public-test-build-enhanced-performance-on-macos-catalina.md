## PCDJ DEX v3.15.0.3 Public Test Build - Enhanced Performance on macOS Catalina

[![DEX 3.15.0.3 FOR MAC PUBLIC BETA | NEW OPTIMIZATIONS FOR MACOS CATALINA](https://i2.wp.com/pcdj.com/wp-content/uploads/2020/11/dex315macos-1.jpg?resize=845%2C321&ssl=1)](https://i2.wp.com/pcdj.com/wp-content/uploads/2020/11/dex315macos-1.jpg?fit=1030%2C581&ssl=1 "DEX 3.15.0.3 FOR MAC PUBLIC BETA | NEW OPTIMIZATIONS FOR MACOS CATALINA")

**A public beta of DEX 3.15.0.3 for macOS is available for download, now with further optimizations for macOS Catalina.** 

As we announced in previous weeks, DEX 3.15 (and up) now support [Beatport LINK and Beatsource LINK](https://tools.techidaily.com/pcdj/products/). Support for the two DJ-centric streaming services means DEX 3 DJ’s can access and stream millions of tracks from premium artists and producers from within the DEX 3.15 browser.

This new public beta is specific for macOS and includes a number of under-the-hood tweaks and optimizations for macOS Catalina. Specifically, DEX 3 version 3.15.0.3 should manage larger music/video/karaoke libraries more efficiently, and manage resource loading better overall. What does that mean for DEX 3 macOS Catalina users? A smoother overall experience mixing during live performance and speedier searching.

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2020/10/macbook-pro-retina.png?fit=300%2C162&ssl=1 "DEX 3 DJ software with LINK streaming support")](https://i2.wp.com/pcdj.com/wp-content/uploads/2020/10/macbook-pro-retina.png?fit=919%2C497&ssl=1)

Be sure to review [this blog post](https://tools.techidaily.com/pcdj/products/) for all the details regarding the new Beatport LINK and Beatsource LINK beta support built into DEX 3.15 as well as the new [key detection/key mixing features](https://tools.techidaily.com/pcdj/products/).

Since DEX 3.15.0.3 for macOS with LINK streaming support is a public beta, if you run into any issues you can share them with the user community on the [Official PCDJ Facebook User Group](http://www.facebook.com/groups/pcdjusergroup/).

For additional information about [Beatport LINK and Beatsource LINK](https://tools.techidaily.com/pcdj/products/) support, including the various tiers and pricing options, please [click here](https://tools.techidaily.com/pcdj/products/).
